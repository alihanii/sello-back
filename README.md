# Sello Backend — FastAPI (فاز ۱)

فرانت‌اند: https://github.com/alihanii/sello-front

سند کامل محصول و طراحی: `specs/sello-phase1-spec.md` (در پوشهٔ پروژه).

## اجرای سریع (توسعه)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env
.venv/bin/python -m scripts.demo_seed      # اختیاری: دادهٔ دمو
.venv/bin/uvicorn app.main:app --port 8000

# فرانت
cd frontend
npm install
cp .env.example .env.local
npm run dev                                 # http://localhost:3000
```

با Docker: `docker compose up --build` (Postgres + بک‌اند + فرانت).

### ورود دمو
در حالت `SELLO_OTP_DEV_MODE=true` کد تأیید در پاسخ API و روی صفحهٔ ورود نمایش داده می‌شود.

| نقش | موبایل |
|---|---|
| فروشنده (بوتیک مهتاب) | `09121234567` |
| ادمین | `09120000000` |

تست‌ها: `cd backend && .venv/bin/pytest`

## معماری

- **backend/** FastAPI + SQLAlchemy async (SQLite در توسعه، Postgres در تولید).
  - `app/models.py` همهٔ جدول‌ها؛ `operations` + `operation_steps` هم صف کار است هم «مرکز وضعیت»: هر اتصال، انتشار، کراول، ساخت با AI مرحله‌به‌مرحله با درخواست/پاسخ (اسرار حذف‌شده)، مدت و دلیل خطای فارسی ثبت می‌شود.
  - `app/services/worker.py` ورکر درون‌پردازه‌ای + زمان‌بند (کراول‌های زمان‌دار، اتوماسیون روزانه). برای مقیاس بالا قابل جایگزینی با Redis/Arq.
  - `app/platforms/` آداپتورها: تلگرام و بله (Bot API رسمی با بات خود فروشنده)، دیجی‌کالا (اتصال OTP و کراول محصولات؛ انتشار در نسخهٔ بعد)، اینستاگرام (Graph API، پشت فلگ `SELLO_INSTAGRAM_ENABLED`). منطق کپشن، پارسر قیمت/موجودی و جریان دیجی‌کالا از platform-wrappers پورت شده.
  - `app/services/ai.py` لایهٔ AI: کلیدها و مسیر هر کار (استخراج، ساخت از رفرنس، تحلیل عکس، سبک فروشگاه…) از پنل ادمین می‌آید؛ پشتیبان خودکار و ثبت مصرف/هزینه/خطا برای مانیتورینگ. هیچ کلیدی در کد نیست.
- **frontend/** Next.js 15 (App Router) + Tailwind v4، طراحی Liquid Glass، RTL با فونت وزیرمتن، حالت روشن/تیره، TanStack Query، به‌روزرسانی زندهٔ عملیات با SSE.

## وضعیت فاز ۱

انجام‌شده: چندفروشگاهی، اتصال کانال‌ها با بررسی سلامت، هاب محصولات (منبع کراول/دستی/AI، موجودی، وضعیت انتشار هر کانال و انتشاردهنده)، انتشار و انتشار گروهی، اتوماسیون و تأیید، کراول و صندوق پیش‌نویس، ساخت محصول از عکس/لینک/سبک کانال، مرکز وضعیت و لاگ مرحله‌ای، تقویم حرفه‌ای (ماه/سال/روز)، صفحهٔ چت «به‌زودی»، پلن‌ها و درخواست خرید، پنل ادمین (کاربران، فروشگاه‌ها، کانال‌ها، فعال‌سازی پلن، پلن‌ها، کلیدهای AI و مانیتورینگ، لاگ ادمین).

مرحلهٔ بعد: انتشار در دیجی‌کالا (پایپ‌لاین ۵ مرحله‌ای platform-wrappers)، فعال‌سازی انتشار اینستاگرام، درگاه پیامک، درگاه پرداخت، دیوار، ایجنت چت.
