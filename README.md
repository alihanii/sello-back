# Sello Backend — FastAPI (فاز ۱)

فرانت‌اند: https://github.com/alihanii/sello-front

سند کامل محصول و طراحی: `specs/sello-phase1-spec.md` (در پوشهٔ پروژه).

## اجرای سریع (توسعه)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env
.venv/bin/uvicorn app.main:app --port 8000

# فرانت
cd frontend
npm install
cp .env.example .env.local
npm run dev                                 # http://localhost:3000
```

با Docker: `docker compose up --build` (Postgres + بک‌اند + فرانت).

### ورود
در حالت `SELLO_OTP_DEV_MODE=true` کد تأیید در پاسخ API و روی صفحهٔ ورود نمایش داده می‌شود.

| نقش | موبایل |
|---|---|
| فروشنده | هر شماره‌ای (ثبت‌نام خودکار) |
| ادمین | شماره‌های `SELLO_ADMIN_PHONES` (پیش‌فرض `09120000000`) |

دیتای دمو وجود ندارد؛ همه‌چیز از صفر و واقعی ساخته می‌شود.

تست‌ها: `cd backend && .venv/bin/pytest`

## معماری

- **backend/** FastAPI + SQLAlchemy async (SQLite در توسعه، Postgres در تولید).
  - `app/models.py` همهٔ جدول‌ها؛ `operations` + `operation_steps` هم صف کار است هم «مرکز وضعیت»: هر اتصال، انتشار، کراول، ساخت با AI مرحله‌به‌مرحله با درخواست/پاسخ (اسرار حذف‌شده)، مدت و دلیل خطای فارسی ثبت می‌شود.
  - `app/services/worker.py` ورکر درون‌پردازه‌ای + زمان‌بند (کراول‌های زمان‌دار). برای مقیاس بالا قابل جایگزینی با Redis/Arq.
  - `app/platforms/` آداپتورها: تلگرام و بله (Bot API رسمی با بات خود فروشنده)، دیجی‌کالا (اتصال OTP، کرال، و انتشار: دسته ← پیش‌نویس ← ویژگی‌ها ← عنوان ← عکس ← ثبت و ارسال برای بررسی)، اینستاگرام (API رسمی Instagram Login روی graph.instagram.com؛ شناسه/کلید اپ Meta و پروکسی از پنل ادمین › یکپارچه‌سازی‌ها). منطق کپشن، پارسر قیمت/موجودی و جریان دیجی‌کالا از platform-wrappers پورت شده.
  - `app/services/ai.py` لایهٔ AI: کلیدها و مسیر هر کار (استخراج، ساخت محصول با AI، تحلیل و ساخت عکس…) از پنل ادمین می‌آید؛ پشتیبان خودکار و ثبت مصرف/هزینه/خطا برای مانیتورینگ. هیچ کلیدی در کد نیست.
- **frontend/** Next.js 15 (App Router) + Tailwind v4، طراحی Liquid Glass، RTL با فونت وزیرمتن، حالت روشن/تیره، TanStack Query، به‌روزرسانی زندهٔ عملیات با SSE.

## وضعیت فاز ۱

انجام‌شده: چندفروشگاهی، اتصال کانال‌ها با بررسی سلامت، هاب محصولات (منبع کراول/دستی/AI، موجودی، وضعیت انتشار هر کانال و انتشاردهنده)، انتشار و انتشار گروهی، کراول و صندوق پیش‌نویس، ساخت محصول با AI از عکس و توضیح، همراه با عکس تمیز، مرکز وضعیت و لاگ مرحله‌ای، تقویم حرفه‌ای (ماه/سال/روز)، صفحهٔ چت «به‌زودی»، پلن‌ها و درخواست خرید، پنل ادمین (کاربران، فروشگاه‌ها، کانال‌ها، فعال‌سازی پلن، پلن‌ها، کلیدهای AI و مانیتورینگ، لاگ ادمین).


### اینستاگرام در محیط واقعی
- حساب Business یا Creator، اپ Meta با `instagram_business_basic` و `instagram_business_content_publish` (برای کاربران عمومی App Review لازم است).
- `SELLO_PUBLIC_BASE_URL` باید دامنهٔ عمومی بک‌اند باشد؛ اینستاگرام عکس JPEG را از همین آدرس دانلود می‌کند.
- `SELLO_FRONTEND_BASE_URL` آدرس فرانت است؛ Redirect URI در پنل ادمین نمایش داده می‌شود.
- اگر سرور داخل ایران است، پروکسی خارج از ایران را در پنل ادمین وارد کنید. سقف API: ۱۰۰ پست در ۲۴ ساعت.

### درگاه پرداخت
خرید آنلاین پلن با کتابخانهٔ `az-iranian-bank-gateways` (زرین‌پال، زیبال، ایران‌درگاه، باهمتا، سامان، ملی، ملت). این کتابخانه برای Django نوشته شده؛ در `app/services/bank.py` یک Django بدون view و middleware داخل همین پروسهٔ FastAPI راه‌اندازی می‌شود که جدول خودش را در `bank.db` (`SELLO_BANK_DB_PATH`) نگه می‌دارد. مشخصات درگاه از پنل ادمین › یکپارچه‌سازی‌ها وارد می‌شود. بانک کاربر را به `/api/v1/payments/callback/` برمی‌گرداند؛ این آدرس روی سرور واقعی باید عمومی باشد (`SELLO_PUBLIC_BASE_URL`). پرداخت موفق، اشتراک را خودکار فعال می‌کند.

### دیجی‌کالا
انتشار از طریق APIهای پنل فروشندگان انجام می‌شود (غیررسمی؛ ممکن است تغییر کنند). محصول بعد از ثبت به صف بررسی دیجی‌کالا می‌رود؛ قیمت و موجودی بعد از تأیید در پنل دیجی‌کالا ثبت می‌شود.

### دستیار چت فروش (تلگرام و بله)
سند کامل: `specs/sello-chat-spec.md` (در پوشهٔ پروژه).
- دو راه اتصال: **بات مستقل** (تلگرام و بله) و **اتصال به پیوی** با Telegram Business (فقط تلگرام؛ حساب Premium و Business Mode در BotFather لازم است). API ربات بله حالت Business ندارد.
- دریافت پیام: پیش‌فرض long polling داخل همین پروسه (روی لوکال/ویندوز بدون دامنه کار می‌کند). روی سرور با چند نمونه: `SELLO_CHAT_TRANSPORT=webhook` و `SELLO_PUBLIC_BASE_URL` با https.
- کم‌هزینه: هر نوبت حداکثر یک فراخوانی مدل؛ خوشامد، FAQ، سلام/تشکر، خارج از ساعت کاری، تأیید سفارش و دریافت فیش بدون مدل. پیشوند ثابت پرامپت برای کش، ۵ محصول مرتبط، ۶ پیام آخر، سقف ۴۰۰ توکن خروجی، تجمیع پیام‌های پشت‌سرهم.
- مسیر مدل: پنل ادمین › هوش مصنوعی › مسیر کارها › «دستیار چت فروش» (پیشنهاد: یک مدل flash-lite).
- `app/services/chat_engine.py` منطق هر نوبت، `chat_runtime.py` دریافت/ارسال و polling، `chat_messenger.py` Bot API، `app/routers/chat.py` API.

مرحلهٔ بعد: درگاه پیامک، دیوار، دایرکت اینستاگرام برای دستیار چت.
